运行与脚本:
- `npm run dev`  : 启动开发服务器（Next.js dev 模式）
- `npm run build` : 打包生产构建（Next.js build）
- `npm run start` : 启动已构建的生产应用（Next.js start）
- `npm run lint`  : 运行 ESLint

重要环境变量:
- `NEXT_PUBLIC_API_URL` : 后端基础 URL，示例 `https://api.example.com`。
- `NODE_ENV` : `development` / `production`，由构建/运行环境设置。

开发约定与风格:
- 组件以功能或领域划分到 `components/` 子目录（如 `Projects/`, `Teams/`）。文件名使用 `PascalCase`（例如 `ProjectCard.tsx`）。
- 页面路由使用 App Router 的文件夹结构（`app/projects/[id]/page.tsx`）。动态段用方括号表示。
- `lib/api.ts` 作为所有后端接口的单一客户端封装，按模块组织（authApi, projectApi, teamApi 等）。
- 类型声明集中在 `types/index.ts`，尽量在接口层使用明确的 TypeScript 类型并在组件间复用。
- 样式采用 TailwindCSS，全局样式放在 `app/globals.css`，组件局部样式使用 `className`。
- 所有网络请求应处理失败情形，统一在 `components/Common/Loading.tsx` 与错误边界 `components/Common/ErrorBoundary.tsx` 上做容错展示。

认证策略:
- **单轨认证**：只存储 JWT token 到 localStorage
- 用户信息通过 `/api/auth/me` 接口获取，不存储到 localStorage
- `context/AuthContext.tsx` 管理全局认证状态
- `lib/auth.ts` 提供认证工具函数（isAuthenticated, getToken, clearAuth）
- 避免双轨存储，确保数据一致性

状态管理:
- 使用 React Context 管理全局状态（AuthContext）
- 组件内部使用 useState 管理局部状态
- 复杂状态可考虑使用 useReducer 或引入 Zustand/Redux

权限控制:
- 前端根据用户角色（user.role）进行条件渲染
- 敏感操作在调用 API 前进行权限检查
- 管理后台路由需要 admin 或 super_admin 角色

错误处理:
- API 调用统一在 `lib/api.ts` 中处理 HTTP 错误
- 使用 try-catch 捕获异步操作异常
- 用户友好的错误提示（alert 或 toast）

目录职责（要点）:
- `app/`：页面与根布局。所有页面放这里，跨页面布局和 Providers 放在 `app/layout.tsx`。
- `components/`：可复用 UI 组件，按域分文件夹。组件应小且职责单一（展示/容器分离）。
- `context/`：React Context（例如 `AuthContext.tsx`）用于管理全局状态（用户、主题等）。
- `hooks/`：可复用 Hook（`useAuth`, `useApi` 等），将副作用逻辑从组件抽离。
- `lib/`：工具层（`api.ts`, `auth.ts`, `utils.ts`），对外提供清晰的函数接口。
- `types/`：TS 类型定义（实体与接口返回类型）。
- `public/`：图片、favicon 等静态资源。

代码质量与 CI 建议:
- 在 CI 中运行 `npm run build` 与 `npm run lint`，确保构建通过且无明显代码风格问题。
- 推荐添加 `prettier` 与 `husky` + `lint-staged` 做提交前格式化与静态检查（可选但建议）。

如何本地运行（快速指南）:
1. 安装依赖（建议使用 pnpm）：
```powershell
pnpm install
```
2. 在项目根（`frontend/`）创建环境变量文件 `.env.local`，示例内容：
```
NEXT_PUBLIC_API_URL=http://localhost:8080
```
3. 启动开发服务器：
```powershell
npm run dev
```
4. 构建生产包并本地预览：
```powershell
npm run build
npm run start
```
